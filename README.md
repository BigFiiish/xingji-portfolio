# Xingji Yan — Portfolio

**Live:** [www.xingjiyan.com](https://www.xingjiyan.com)

Selected systems, nine evidence-led case studies, and an engineering writing archive. The homepage pairs a short Now / Looking for narrative with an accessible nine-project topology, three flagship systems, six compact projects, and four concise failure guarantees. Each project has a durable URL, a distinct social card, explicit ownership, verified proof, tradeoffs, and a “What I would improve next” section. Featured work includes [CrawlForge](https://xingji-crawlforge.onrender.com), a Java/Spring careers intelligence crawler with structured job extraction, JSON/CSV export, and optional AI-assisted matching. M.S. ECE, Carnegie Mellon.

The writing archive covers bounded web crawling, transactional idempotency, deterministic agent evaluation, and durable human approval. Every essay records its published and updated dates, includes an accessible decision diagram, links claims to commit-pinned source code and primary references, and connects to related essays.
