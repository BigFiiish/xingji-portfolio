2026 · Dockline · JASCI

The model is never the judge.

If the model grades the model, you will ship a confident wrong tool call.

That is not a philosophy. It is a production incident waiting for a warehouse. An ops agent that can release a wave, look up another tenant, or invent a JSON field does not get to score itself. Confidence is not evidence.

At JASCI I put an LLM on top of systems that already had to be correct: tenant isolation, idempotent writes, audit rows. The useful part was not the chat. The useful part was the contract. Schema. Role. A trace you can read when it fails.

Dockline is that contract as a product. Forty cases. The default router is deterministic. OpenAI tools are optional. The scorer is a rule file. The model, when it is present, is an untrusted caller — the same as a browser, the same as a retry.

Schema, then auth, then execute. Extra fields die at schema. Cross-tenant prompts die at auth. The execute step never sees a guess. You can watch that path fail closed in Hallucinate.

People ask for an eval harness after the demo works. That is backwards. The harness is the product. Cases are cheaper than a wrong wave.

I want the seat where this can go wrong: on-call for tenants, retries, and agents that fail closed. If the judge floats, I do not ship.
